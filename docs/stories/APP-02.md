# APP-02 Search for a book by title and see covers and badges

Status: todo
Milestone: 2
Depends on: BRK-02, BRK-07

## Story

As a reader, I want one search field with results that show real covers and "in library" / owner badges,
so that I can tell at a glance whether we already have a book.

## Acceptance criteria

- [ ] Search home with one field, language chips (any / English / Nederlands)
- [ ] Each hit shows cover, title, author, series and badges (On your Kobo, Partner has it)
- [ ] Copy makes clear that looking is free and only Add spends a search
- [ ] Indexer budget pill shows searches left this hour
- [ ] Empty, loading and error states are translated
