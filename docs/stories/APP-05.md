Status: todo

## Story

As a reader, I want to follow a request live and swap the release if the pick looks wrong,
so that I stay in control without spending extra searches.

## Acceptance criteria

- [ ] Requests screen shows each step live over SSE
- [ ] "Pick another" opens the release list from the search already done (free)
- [ ] Release picker explains format, size, language and why items were left out
- [ ] Not found shows "Try again" with its cost
