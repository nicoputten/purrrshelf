# Import library

Not on the canvas yet. Story: BRK-09. Opened from Settings → Library →
"Import Calibre library".

Built in BRK-09:

- Back button and the title "Import library", then one muted line: "Brings in
  the books already in Calibre. Then say whose each book is."
- A card with the last run and one button. Before the first run: "Not scanned
  yet." and "Scan library". While matching: "Matching books to search
  results… 12 of 80" (read out politely by screen readers, refreshed every
  2 seconds) and a busy button. Afterwards: "Found 80 books, 80 new.", a muted
  "62 matched to a book on Search, 18 not." and, when search failed for some,
  "Search did not answer for 3 books. Scan again to try those again." The
  button then says "Scan again".
- Chips: "Nobody's yet · 18" (default) and "All · 80". Books are sorted by
  title.
- Bulk: "Give all 18 shown to" with one small outline button per choice: Me,
  the partner's name, Both (Everyone with more than two readers).
- One card per book: title in bold, authors muted, and a segmented control
  with the same choices showing the book's current owners. Tapping one
  assigns the book right away; in "Nobody's yet" the book then leaves the
  list.
- 50 books at first, then "Show 18 more".
- Empty states: "No books found yet. Scan the library first." and "Every book
  has an owner." Errors show as one translated sentence.
